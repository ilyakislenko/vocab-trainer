# Abstract collocations

Abstract nouns (*impact, scope, assumption, constraint*) are lifeless on their
own. They gain meaning when paired with the verbs and adjectives that native
speakers expect around them.

## Verbs that carry abstract nouns

| Noun | Verbs it pairs with |
|---|---|
| assumption | make, question, challenge, test |
| constraint | impose, remove, relax, work within |
| impact | have, make, assess, mitigate |
| insight | gain, offer, provide, draw |
| evidence | provide, gather, weigh, review |
| hypothesis | form, test, support, reject |

*We **challenged the assumption** behind the plan.* — never "took an assumption".

## Adjectives that sharpen abstract nouns

- **significant impact / substantial evidence / profound insight**
- **underlying assumption / key constraint / rigorous analysis**
- **broad scope / narrow scope / unintended consequence**

## Argumentation chains

- *We **formed a hypothesis**, **gathered evidence**, and **drew a conclusion**.*
- *The findings **support the hypothesis**; the data **raise new questions**.*

## Common mistakes

| Correct | Common mistake |
|---|---|
| **question the assumption** | take the assumption |
| **have an impact** | do an impact |
| **draw a conclusion** | make a conclusion |
| **impose a constraint** | put a constraint on — OK, but impose is formal |

## Strategy

For every abstract noun, learn its **verb family** (make/do/take/gain/have) and
its **adjective family** (significant/critical/underlying). Use one collocation
chain per argument.

## Quick check

- *We ___ the assumption behind the proposal.* → **challenged**
- *The findings ___ strong evidence.* → **provide**
- *We need to ___ a hypothesis first.* → **form**
- *The change had a ___ impact.* → **significant**

Abstract nouns are skeletons; collocations are the muscles. Attach the right verb and the sentence stands up.
