# Academic collocations

A collocation is a **pair of words that native speakers always combine**: *make a
decision*, *draw a conclusion*. Word-for-word translation from Russian produces
collocations that sound foreign.

## Verb + noun — the high-frequency pairs

| Verb | Noun |
|---|---|
| make | a decision, a mistake, progress, an effort |
| draw | a conclusion, attention |
| take | action, steps, responsibility, into account |
| reach | a consensus, an agreement |
| pose | a problem, a challenge, a threat |
| carry out | research, an investigation |
| conduct | a survey, an analysis |
| meet | a requirement, a deadline |

*We **drew a conclusion** from the data.* — never "made a conclusion".

## Adjective + noun

- **significant** improvement / **substantial** evidence
- **key** factor / **critical** issue / **crucial** role
- **major** impact / **minor** issue
- **mutual** benefit / **shared** responsibility

## Common mistakes

| Correct | Common mistake |
|---|---|
| make **progress** | do progress |
| draw **a conclusion** | make a conclusion |
| meet **a deadline** | hold a deadline |
| **take into account** | take in attention |

## Strategy

Learn verbs by their **noun partners** (make/do/take/get + their nouns) rather
than each word alone. When writing, ask: *does this verb normally pair with this
noun in English?* If unsure, choose the safest common pair.

## Quick check

- *We need to ___ a decision by Friday.* → **make**
- *The survey ___ several problems.* → **posed**
- *She ___ out the research.* → **carried**
- *It's a ___ factor in the design.* → **key**

Collocations are pre-built chunks. Learn the chunk, not the word, and your writing instantly sounds more natural.
