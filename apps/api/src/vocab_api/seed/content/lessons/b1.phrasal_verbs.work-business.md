# Phrasal verbs: work and business

A phrasal verb is **verb + particle** whose meaning is a single unit. In a
business context you hear them constantly: *follow up, put off, carry out,
bring in, lay off, take over, back up, break down*.

## Work & business essentials

| Phrasal verb | Meaning | Example |
|---|---|---|
| follow **up** | check on progress | Let's follow up on the quote. |
| put **off** | postpone | We put the launch off. |
| carry **out** | perform, complete | We carried out a review. |
| bring **in** | earn / hire | New features brought in revenue. |
| back **up** | support / copy data | Back up the files first. |
| break **down** | stop working / fail | The system broke down. |
| take **over** | assume control | A bigger firm took over. |
| lay **off** | dismiss staff | They laid off a team. |

## Separable vs inseparable — the key rule

- **Separable**: pronoun must go in the middle: *put **it** off*, *back **them** up*.
- **Inseparable**: stays together: *call **on** a client* (not "call on him" → correct is
  "call on him"; but "call him up" is fine because *up* is separable).

If the particle is **preposition-like** (on, for, with, into), the verb is
usually inseparable and the object follows the whole verb.

## Common mistakes

| Correct | Common mistake |
|---|---|
| We put **it** off. | We put off **it**. (pronoun in the middle) |
| Please call **them** up. | Please call up them. |
| She takes **after** her father. | She takes after him (OK) → not "takes him after". |

## Strategy

Learn phrasal verbs in **topic groups** (work, communication, problems) and
memorise the pronoun position for each. Test yourself by swapping the object
for *it/them* — if it sounds wrong, the verb is inseparable.

## Quick check

- *We had to ___ the meeting because of a conflict.* → **put off**
- *Please ___ the files before the update.* → **back up**
- *The software ___ and we lost the session.* → **broke down**
- *Let me ___ on that email.* → **follow up**

One unit, one meaning. Learn the pair, then place the pronoun correctly.
