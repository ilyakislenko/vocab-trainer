# Dependent prepositions: depend on, responsible for

Some words demand a **fixed preposition** you cannot derive from logic — you
memorise the pair. A wrong preposition instantly flags a non-native speaker.

## Common fixed pairs

| Verb + prep | Adjective + prep | Noun + prep |
|---|---|---|
| depend **on** | responsible **for** | interest **in** |
| wait **for** | good **at** | reason **for** |
| apply **for** | interested **in** | answer **to** |
| listen **to** | afraid **of** | effect **on** |
| pay **for** | similar **to** | problem **with** |

## Patterns by word type

- **Verb + object + preposition** can vary: *blame someone **for**, provide someone **with**,
  compare something **to**.*
- A verb's own preposition changes meaning: *look at* (see), *look for* (search),
  *look after* (take care of), *look forward to* (anticipate).

## Common mistakes

| Correct | Common mistake |
|---|---|
| depend **on** | ~~depend from~~ |
| responsible **for** | ~~responsible on~~ |
| interested **in** | ~~interested about~~ |
| good **at** | ~~good in~~ |
| wait **for** | ~~wait a bus~~ (need the preposition!) |

## Strategy

1. Learn the **word + preposition** as one unit, not the word alone.
2. When unsure, test with a dictionary — there is no rule that predicts every pair.
3. Watch for *verb + to* vs *verb + -ing* after the object: *look forward **to doing**
   something* (to is a preposition here, not an infinitive marker).

## Quick check

- *The result depends ___ the input.* → **on**
- *Who is responsible ___ this bug?* → **for**
- *I'm not very good ___ presentations.* → **at**
- *She's interested ___ machine learning.* → **in**

Treat each pair as a stored chunk. Get the chunk right and the sentence builds itself.
