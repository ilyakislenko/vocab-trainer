# Passive voice and the agent

The passive moves the **focus** from who did the action to the action itself or
its result: *The report was finished.* We reach for it when the agent is
**unknown, obvious, or unimportant**.

## Form: be + V3

The tense lives in the auxiliary `be`:

| Tense | Passive |
|---|---|
| Present simple | is/are **built** |
| Past simple | was/were **built** |
| Present perfect | have/has **been built** |
| Past perfect | had **been built** |
| Will | will **be built** |
| Modal | must **be built** |

- *The app **is developed** in-house.*
- *A new version **has been released**.*

## The agent (by …)

Include `by` only when the agent matters:

- *The system was built **by our team**.* (who did it is new info)
- *The report was published.* (agent obvious — the company)

## Impersonal passive — a formal tool

- *It **is said that** … / It **is believed that** …*
- *The problem **is considered** serious.*
- Use for hedging in reports and meetings.

## Common mistakes

| Correct | Common mistake |
|---|---|
| The bug **was fixed**. | The bug was fixed **by someone** — not wrong, just wordy. |
| It **is believed** that… | It **believes** that… (no agent-less active) |
| The code **has been reviewed**. | The code is been reviewed. |

## Get vs be

`get + V3` is informal passive for unexpected events: *Our server **got** hacked.*
Use it in speech, avoid in formal writing.

## Quick check

- *A decision ___ been made.* → **has**
- *The contract ___ signed tomorrow.* → **will be**
- *This feature ___ introduced in v2.* → **was**
- *It is ___ that prices will rise.* → **believed**

Focus decides the voice. If the doer is unimportant, drop it; if it matters, keep *by*.
