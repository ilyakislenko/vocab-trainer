# Modal verbs: can, must

Modal verbs are special helpers: they stay the same for every person, and the
main verb after them is always the **base form**.

## can — ability and permission

- *I **can** swim.* (ability)
- ***Can** I open the window?* (permission)
- *You **can't** park here.* (no permission)

Negative: **cannot / can't**.

## must — obligation

- *You **must** wear a helmet.* (it is necessary)
- *You **mustn't** smoke here.* (prohibited)

Negative: **must not / mustn't** means *it is forbidden*.

## No -s, no to

The modal never changes and never takes *to*:

- *She **can drive**.* (not "She cans drive" or "She can to drive")
- *We **must leave** now.*

## Common mistakes

| Correct | Common mistake |
|---|---|
| He **can speak** three languages. | He cans speak … / He can speaks … |
| **Can** I help you? | I can help you? |
| You **mustn't** be late. | You mustn't to be late. |

## Quick check

- *I ___ play the guitar.* (ability) → **can**
- *You ___ pay online; it's the only option.* (obligation) → **must**
- *Visitors ___ touch the paintings.* (forbidden) → **mustn't**
