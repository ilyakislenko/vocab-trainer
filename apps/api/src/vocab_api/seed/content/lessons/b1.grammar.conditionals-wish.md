# Conditionals and wish

Conditionals express **how likely a condition is**. English picks the verb form
by *distance from reality*, not by real time. That is the key insight.

## The three main types

| Type | Meaning | Form | Example |
|---|---|---|---|
| Zero/First | real, possible | `if + present, will/can` | If it **rains**, we **will** cancel. |
| Second | unreal now | `if + past, would` | If I **had** time, I **would** help. |
| Third | unreal past | `if + had V3, would have V3` | If I **had known**, I **would have come**. |

**Zero** (`if + present, present`) is for facts: *If you heat water, it boils.*

## Second conditional — distance, not past tense

`If I were you…` looks like past tense but is *unreal now*. Use **were** for all
subjects in formal English: *If she were here, she'd agree.*

- `If I had more money, I would travel more.` (I don't have it → unreal)

## Third conditional — the regret

- `If I hadn't missed the bus, I wouldn't have been late.`
- Note the double past: condition in past perfect, result in `would have V3`.

## wish

- `wish + past` — unreal present: *I wish I **knew** the answer.*
- `wish + past perfect` — regret about the past: *I wish I **had studied** harder.*
- `wish + could/would` — desire for change: *I wish the bus **would** come.*

## Common mistakes

| Correct | Common mistake |
|---|---|
| If I **were** you… | If I **was** you… |
| If it rains, we **will** stay. | If it will rain, we stay. (no will in the if-clause) |
| I wish I **had** applied. | I wish I would have applied. (double would) |

## Quick check

- *If I ___ rich, I ___ buy a house.* → **were / would**
- *I wish I ___ taken the job.* → **had**
- *If you ___ the key, you'll find it.* → **look for**

Decide by reality: real → will; unreal now → would + past; unreal past → would have + had V3.
