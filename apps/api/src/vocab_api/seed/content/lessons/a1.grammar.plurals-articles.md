# Plurals & articles

Two small words decide a huge amount of meaning: **a/an** and **the**. This
lesson also covers how nouns go plural.

## Regular plurals

Most nouns add **-s**: *book → books, car → cars*. Add **-es** after *-s, -sh,
-ch, -x, -o*: *bus → buses, box → boxes, dish → dishes*. After a consonant +
*y* change to **-ies**: *city → cities*.

A few common nouns are irregular: *man → men, woman → women, child → children,
foot → feet, tooth → teeth, person → people*.

## a / an

Use **a** before a consonant sound and **an** before a vowel sound — for **one**
thing among many, when the listener is meeting it for the first time:

- *a book, a house, a university* (sounds like *yu-*), *an apple, an hour*
  (silent *h*).

## the

Use **the** when the listener already knows which thing you mean — because you
mentioned it before, or because there is only one:

- *I bought **a** coffee. **The** coffee was hot.* (first mention → known)
- ***The** sun is bright today.* (only one sun)

## Common mistakes

| Correct | Common mistake |
|---|---|
| two **children** | two childs |
| **an** umbrella | a umbrella |
| I saw **a** cat. **The** cat ran away. | I saw the cat. The cat ran away. (first mention needs a/an) |

## Quick check

- *one bus, three ___* → **buses**
- *___ orange on the table.* → **an**
- *I met ___ woman. ___ woman was kind.* → **a … The**
