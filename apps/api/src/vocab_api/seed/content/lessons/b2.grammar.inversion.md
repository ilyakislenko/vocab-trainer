# Inversion after negatives and so

Inversion moves the **auxiliary before the subject** — *Never have I seen…*.
It is the signature of formal, emphatic English.

## After negative adverbials

When the sentence opens with a negative or restrictive phrase, invert:

- *Never **have I** seen such a bug.*
- *Rarely **does** he complain.*
- *Not only **did** she fix it, she wrote docs.*
- *Only then **did** we understand.*
- *Under no circumstances **should** you commit directly.*

## so / such + that

- *So complex **was** the code that nobody dared change it.*
- *Such **was** the pressure that the team split the work.*

## The mechanics

1. Find the auxiliary (`have, do, does, did, was, should`…).
2. Put it before the subject.
3. With no auxiliary, use `do/does/did`: *Rarely **does** she take time off.*

## Common mistakes

| Correct | Common mistake |
|---|---|
| Never **have I** seen… | Never I have seen… (no inversion) |
| Not only **did he** fix… | Not only he did fix… |
| Rarely **does** she… | Rarely she does… |

## Register note

Inversion is **formal** — great for reports, speeches, and technical writing;
in speech it sounds theatrical, so use sparingly.

## Quick check

- *Never ___ I felt so relieved.* → **have**
- *Not only ___ the build fail, it corrupted data.* → **did**
- *Rarely ___ this team miss a deadline.* → **does**
- *Only after the review ___ we deploy.* → **did**

Spot the negative opener → bring the auxiliary forward. One word, big effect.
