# Advanced inversion

Advanced inversion moves past *never/rarely* to the machinery of **agreement,
emphasis, and formal conditionals**. It signals mastery when used precisely.

## Agreement: so / neither / nor

- *We fixed it, and **so did** they.*
- *We didn't deploy, and **neither did** the other team.*
- *The service is down, and **nor is** the backup.*
- Note: *so did / neither did* — auxiliary before subject.

## Hardly / scarcely / no sooner

`Hardly + had + subject + V3` marks two past events in rapid succession:

- ***Hardly had** we shipped when the bug report arrived.*
- ***Scarcely had** I joined when the meeting started.*
- ***No sooner** had the tests passed **than** the client called.*

## Inversion in formal conditionals

Drop `if` and invert:

- *Had we known, we would have stayed.* (If we had known…)
- ***Should** the build fail, we will roll back.* (If the build should fail…)
- ***Were** the deadline closer, I'd say no.* (If the deadline were…)

## Concession and emphasis

- ***However hard** it rains, the servers stay up.*
- ***Much as** I appreciate the offer, I must decline.*

## Common mistakes

| Correct | Common mistake |
|---|---|
| **No sooner had** we shipped… | No sooner we had shipped… (invert) |
| **Had** I known… | If had I known… |
| …and **so did** they. | …and so they did. (agreement inverts) |

## Quick check

- ***Hardly had** the build finished ___ the tests began.* → **when**
- ***Had** we reviewed it, we ___ found the bug.* → **would have**
- *We don't deploy on Friday, and ___ does anyone.* → **neither**

Advanced inversion trades word order for formality. Learn the triggers: so/neither, hardly/no sooner, and the if-less conditional.
