# Modality in the past: should have, needn't have

`modal + have + V3` lets you talk about the past from today's vantage point —
criticism, missed opportunities, and relief.

## The forms

| Form | Meaning | Example |
|---|---|---|
| should have | criticism / regret | You **should have** called. |
| shouldn't have | criticism / regret | We **shouldn't have** skipped the review. |
| could have | missed opportunity | She **could have** warned us. |
| must have | near-certain past | He **must have** forgotten. |
| might have | possible past | They **might have** left. |

## needn't have vs didn't need to — the classic trap

- **needn't have done**: you did it, but it was unnecessary (wasted effort):
  *I **needn't have** booked the room; nobody came.*
- **didn't need to do**: you didn't do it, and it wasn't required:
  *I **didn't need to** book the room, so I didn't.*

## should have vs must have

- *should have* = judgement about what was right.
- *must have* = logical conclusion with no judgement.
  *The deploy must have failed silently — we should have checked the logs.*

## Common mistakes

| Correct | Common mistake |
|---|---|
| You **should have** told me. | You should have tell me. (V3 after have) |
| I **needn't have** worried. | I didn't needn't have worried. |
| She **could have** saved us time. | She could of saved us time. (*of* is wrong for *have*) |

## Quick check

- *You ___ have checked the config first.* → **should**
- *We ___ have rushed; the deadline moved.* → **needn't** (we did rush, unneeded)
- *He ___ have deleted it by accident.* → **might**

Every form judges the past from now. Pick the judgment: criticism → should have, relief → needn't have, deduction → must/might have.
