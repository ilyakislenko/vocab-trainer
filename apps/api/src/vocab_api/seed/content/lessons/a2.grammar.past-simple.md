# Past Simple

Use the **past simple** for finished actions at a finished time: *yesterday,
last week, in 2010, two days ago*. The time is over, and so is the action.

## Regular verbs

Add **-ed** to the base verb. After a consonant + *y*, change *y* → *ied*; a
final *e* just adds *-d*:

- *work → worked, play → played, study → studied, like → liked.*

The form is the same for every person: *I worked, she worked, they worked*.

## Irregular verbs

Many common verbs are irregular and must be memorised:

| Base | Past |
|---|---|
| go | went |
| have | had |
| see | saw |
| eat | ate |
| buy | bought |
| take | took |
| do | did |
| make | made |

- *I **went** home at six. She **saw** the film last night.*

## Negatives and questions

Use **did** + base verb. The main verb stays in its base form:

- *I **didn't go** out.* (not "didn't went")
- ***Did** you **watch** the match?* → Yes, I did. / No, I didn't.

## Common mistakes

| Correct | Common mistake |
|---|---|
| She **studied** hard. | She studyed hard. |
| We **went** there. | We goed there. |
| **Did** you **see** him? | Did you saw him? |

## Quick check

- *Yesterday I ___ (walk) to work.* → **walked**
- *He ___ (buy) a new phone.* → **bought**
- *___ she ___ (call) you?* → **Did … call**
