# Imperatives

Use the **imperative** to tell someone to do something. It is just the base
verb, with no subject: ***Sit** down.* For instructions, directions, and
warnings it is the most useful form you have.

## Giving a direct order

- ***Open** the door.*
- ***Read** page five.*
- ***Take** a seat.*

The form is the same for one person or many, and it stays the base verb even
for *be* and *have*: ***Be** careful. **Have** a seat.*

## Negative imperative

Add **don't** before the verb:

- ***Don't** touch** that.***
- ***Don't** be** late.***
- ***Don't** worry.**

## Making it polite

Add **please** at the start or the end:

- ***Please** wait here.* / *Wait here, **please**.*
- *Could you* is even softer, but at A1 level *please* is enough.

## Common mistakes

| Correct | Common mistake |
|---|---|
| **Don't run** in the corridor. | No run in the corridor. |
| **Be** quiet, please. | Be quiet you. |
| **Close** the window. | To close the window. |

## Quick check

- *___ (not / open) the box.* → **Don't open**
- *___ (turn) left at the corner.* → **Turn**
- *___ (be) careful on the stairs.* → **Be**
