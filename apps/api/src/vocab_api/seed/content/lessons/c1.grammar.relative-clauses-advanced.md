# Advanced relative clauses

Beyond who/which lies the machinery of **formal, precise** reference: *whose,
whom*, and *preposition + which*. These give you fine control over what a clause
modifies.

## whose — possession

- *The dev **whose** PR we merged is on leave.*
- *A company **whose** culture is strong retains talent.*

## whom — formal object

- *The candidate **whom** we interviewed was impressive.*
- In speech, most people say *who* or nothing; *whom* signals formal writing.

## Preposition + which — the formal pattern

- *The tool **with which** we deploy is Terraform.*
- *The issue **about which** we argued is settled.*
- Informal: *The tool we deploy with.* / *The issue we argued about.*

## Which referring to a whole clause

- *The build passed, **which** surprised everyone.*
- *We shipped early, **which** was a win.*

## Common mistakes

| Correct | Common mistake |
|---|---|
| The tool **with which** we deploy. | The tool which we deploy with is wrong — actually both are OK; *with which* is formal, *with* at the end is neutral. |
| The person **whose** car… | The person which car… (whose for people) |
| …**, which** surprised us. | …**, that** surprised us. (no that for whole-clause reference) |

## Quick check

- *The team ___ project won…* → **whose**
- *The API, ___ we migrated, is fast.* → **which** (whole clause or thing)
- *The report ___ which we disagreed…* → **about**

Formal relative clauses put the preposition before *which*; everyday English keeps it at the end. Match your audience.
