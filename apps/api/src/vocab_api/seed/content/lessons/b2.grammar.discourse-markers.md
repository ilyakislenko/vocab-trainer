# Discourse markers: however, therefore, moreover

Discourse markers connect **sentences and paragraphs**, not just clauses. They
tell the reader how ideas relate: contrast, result, addition, example.

## The three core jobs

| Job | Markers | Example |
|---|---|---|
| Contrast | however, nevertheless, on the other hand | It was late. **However**, we finished. |
| Result | therefore, consequently, as a result | Tests failed. **Therefore**, we delayed. |
| Addition | moreover, furthermore, in addition | It's fast. **Moreover**, it's free. |

## Punctuation — the trap

- A discourse marker at the start of a sentence takes a comma:
  **However**, we proceed.
- In the middle, it's bracketed by commas: *We, **however**, disagreed.*
- Unlike conjunctions (*but, so*), they cannot join two clauses with just a comma:
  ❌ *It was late, however we finished.* → ✅ *It was late. **However**, we finished.*

## Formal register

These markers are **formal** — the backbone of reports, docs, and cover letters.
In casual chat, *but / so / also* win. Match the marker to the register.

## Common mistakes

| Correct | Common mistake |
|---|---|
| It was late. However, we… | It was late, however we… (comma splice) |
| Tests failed. Therefore, we… | Tests failed, therefore we… |
| It's fast. Moreover, it's free. | It's fast. Moreover, it's free — fine. (wrong: and moreover) |

## Quick check

- *The API is stable. ___, we ship.* → **Therefore**
- *We were short-staffed. ___, we met the deadline.* → **However**
- *The tool is secure. ___, it is easy to use.* → **Moreover**

Pick the job first (contrast/result/addition), then the word. Keep them at the sentence edge with a comma.
