# Phrasal verbs: problem solving

Problem-solving phrasal verbs describe **analysing, investigating, and fixing**
issues — the daily language of debugging and planning.

## Analysis & investigation

| Phrasal verb | Meaning | Example |
|---|---|---|
| look into | investigate | Let's look into the outage. |
| figure out | understand, solve | We figured out the cause. |
| track down | find | They tracked down the leak. |
| dig into | examine deeply | I'll dig into the logs. |
| go through | examine carefully | We went through the code. |
| narrow down | reduce options | We narrowed it down to two causes. |
| rule out | exclude a possibility | We ruled out a network issue. |

## Solving & resolving

| Phrasal verb | Meaning | Example |
|---|---|---|
| sort out | fix, organise | We sorted out the config. |
| work out | resolve by reasoning | We worked out a plan. |
| iron out | remove small problems | We ironed out the bugs. |
| cut out | remove completely | Cut out the dead code. |
| roll back | revert | We rolled back the change. |
| stand by | wait ready | The team stood by. |

## Common mistakes

| Correct | Common mistake |
|---|---|
| We ruled **it** out. | We ruled out it. (pronoun middle) |
| Let's look **into** the issue. | Let's look the issue into. (inseparable) |
| We worked **it** out. | We worked out it. |

## Strategy

Separable particles (`out, up, off`) take the pronoun in the middle. Inseparable
(`into, on, for`) keep the whole verb together. Sort out the particle, and the
sentence follows.

## Quick check

- *We need to ___ down the error.* → **narrow**
- *The team ___ out a network issue.* → **ruled**
- *Let's ___ into the logs.* → **dig**
- *We ___ the deploy back.* → **rolled**

Analyse → investigate → solve: three moves, each with its own phrasal verbs. Learn them as one block.
