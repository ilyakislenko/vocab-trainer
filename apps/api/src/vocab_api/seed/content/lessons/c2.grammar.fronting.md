# Fronting & postponement

**Fronting** moves a sentence element to the first position — ahead of the
subject — to give it emphasis or to link back to the previous sentence.
**Postponement** does the opposite: it moves heavy material to the end, where
long subjects read more naturally.

## Fronting an object or complement

Neutral: *I don't believe his promises.*
Fronted: ***His promises** I don't believe.*

Fronting is a rhetorical choice, common in writing and formal speech. It
signals *"this matters most"*.

## Negative adverbial fronting → inversion

When a negative or restricting adverbial moves to the front, subject and
auxiliary **invert**:

- ***Never** have I seen such a mess.*
- ***Not only** did they miss the deadline, **but** they also hid it.*
- ***Seldom** does the system run this smoothly.*
- ***Hardly** had we started when the network failed.*

Without inversion this is a classic non-native tell: ~~*Never I have seen …*~~

## Postponement

Move a long subject to the end to keep the opening light:

- *It is **hard to justify the cost**.* (postponed subject *to justify the cost*)
- *It **turns out** the results were wrong.*

## Common mistakes

| Correct | Common mistake |
|---|---|
| **Never** have I worked so hard. | Never I have worked so hard. |
| **Rarely** does the server go down. | Rarely the server goes down. |
| *His plans* I found brilliant. | I found *his plans* brilliant. (fine, but fronting is the point here) |

## Quick check

- *___ had she finished when the phone rang.* (negative fronting) → **Hardly**
- *Not only ___ they late, they were unprepared.* → **were**
- Which is postponed: *It is hard to justify the cost.* → the **cost** argument
