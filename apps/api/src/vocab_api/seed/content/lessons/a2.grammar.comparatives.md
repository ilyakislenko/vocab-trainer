# Comparatives & superlatives

You compare two things with the **comparative** and three or more with the
**superlative**. Which form you choose depends on the length of the adjective.

## Short adjectives: -er / -est

- *cheap → cheaper → the cheapest*
- *big → bigger → the biggest* (double the final consonant)
- *easy → easier → the easiest* (y → i)

Use **than** after the comparative: *This hotel is **cheaper than** that one.*

## Long adjectives: more / the most

- *expensive → more expensive → the most expensive*
- *careful → more careful → the most careful*

## Irregular

- *good → better → the best*
- *bad → worse → the worst*
- *far → farther/further → the farthest/furthest*

## As ... as

For equality use **as + adjective + as**: *This flat is **as big as** yours.*
For inequality: **not as ... as** — *My flat is **not as big as** yours.*

## Common mistakes

| Correct | Common mistake |
|---|---|
| more **expensive** | more expensive**r** |
| the **best** | the goodest |
| as tall **as** me | as tall like me |

## Quick check

- *Today is ___ (hot) than yesterday.* → **hotter**
- *This is ___ (good) film I have seen.* → **the best**
- *My bag is ___ heavy as yours.* → **as**
