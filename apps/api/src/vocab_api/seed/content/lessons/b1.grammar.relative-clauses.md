# Relative clauses: who, which, that, where

A relative clause **identifies** or **adds information** about a noun. The
pronoun you choose depends on what you are describing.

## Choosing the pronoun

| Pronoun | Describes | Example |
|---|---|---|
| who | people | The dev **who** fixed it is great. |
| which / that | things | The bug **which** we found… |
| where | places | The repo **where** we host docs… |
| whose | possession | The team **whose** PR won… |

`that` can replace `who/which` in **defining** clauses: *the bug that we found*.

## Defining vs non-defining

- **Defining** — essential, no commas: `The engineer who wrote this is on leave.`
  (removing it changes the meaning: which engineer?)
- **Non-defining** — extra info, with commas, never `that`: `Our engineer, who is
  on leave, wrote this.` (there is only one engineer; info is bonus)

## Omitting the pronoun

You may drop `who/which/that` when it is the **object** of the clause:

- `The report (which) I sent` — I sent *it* → object → can omit.
- `The person who called` — *they* called → subject → cannot omit.

## Common mistakes

| Correct | Common mistake |
|---|---|
| The tool **that/which** I use. | The tool **what** I use. (what never introduces a relative clause) |
| Our CTO, **who** lives in Berlin, … | Our CTO, **that** lives in Berlin, … (no that in non-defining) |
| The office **where** we work. | The office **which** we work. (place → where) |

## Quick check

- *The person ___ signed the contract* → **who**
- *The city ___ I grew up* → **where**
- *The files ___ you need are here* → **that** (or omit)

Is the info essential? Yes → no commas, `that` allowed. No → commas, never `that`. Object position → pronoun optional.
