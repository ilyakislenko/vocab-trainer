# Technology vocabulary

Precise tech vocabulary separates vague claims from clear ones. *The system is
slow* tells little; *the API has high latency under load* tells everything.

## Software & development

| Word | Meaning / use |
|---|---|
| deploy | release to production |
| maintain | keep working over time |
| refactor | restructure without changing behaviour |
| roll out | introduce gradually |
| robust | handles errors gracefully |
| legacy | old, still running |
| backward compatible | works with old versions |

## Infrastructure

- **load**: demand on a system — *high load, under load, handle the load*.
- **throughput**: work done per time unit.
- **latency**: delay — *high latency = slow response*.
- **redundancy**: duplicate components for safety.
- **scalable**: grows with demand.

## Data & analysis

| Word | Meaning |
|---|---|
| ingest | bring data in |
| pipeline | the end-to-end flow |
| transform | change data shape |
| aggregate | combine into summaries |
| anomaly | unusual value to investigate |

## Common mistakes

| Correct | Common mistake |
|---|---|
| The service is **robust**. | The service is strong like a tree. (robust has a specific meaning) |
| We **rolled out** the update. | We made the update to production. |
| High **latency** | Big delay — both work, but latency is precise. |

## Strategy

Learn words in **mini-sets by domain** (dev, infra, data) and test yourself by
matching a word to its one-line definition. Use the technical word over its
generic synonym when discussing systems.

## Quick check

- *A service that handles errors well is ___.* → **robust**
- *The time delay in a response is ___.* → **latency**
- *To bring data into the system is to ___ it.* → **ingest**
- *A system that grows with demand is ___.* → **scalable**

Precision is power in tech English. One domain, one mini-set, then drill until the words are automatic.
